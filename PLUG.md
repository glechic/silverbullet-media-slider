A SilverBullet plug that renders a media slider/carousel inside fenced `media-slider`
code blocks, inspired by the Obsidian "Media Slider" plugin.

Supports images, videos, audio, PDFs, markdown-file slides, thumbnails, captions,
transition effects, autoplay, keyboard / wheel / touch navigation, and folder
expansion. See the plug's own page for full usage.
